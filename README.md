# Audio_Metadata_and_Art-releases
You point this app at your music library — the folders where your albums live, one folder per artist and one per album. The app figures out **which artist and which album each folder actually is**, then goes out to the internet to collect the missing pieces: biographies, genres, release dates, ratings, and all the artwork (covers, disc art, logos, banners, backgrounds). Finally it writes that information back into your folders as neat, standard files (artist.nfo, album.nfo, cover.jpg, and so on) that media players like Kodi and JRiver understand.

It needs the .NET 8 Desktop Runtime (x64) and FFmpeg 7.x shared libraries.
